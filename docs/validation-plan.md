# Independent Validation Plan

The next validation should apply EGASE v0.1 to an independent software project without importing a large pre-existing governance stack.

Measure at minimum:

- human interventions per material change;
- repeated agent cycles and rework;
- governance artifacts created versus artifacts that changed a decision;
- defects found before merge and after merge;
- evidence quality;
- observable signs of Reasoning Preservation;
- token/compute cost where available;
- time-to-validated-change.

The purpose is to falsify or support the hypothesis that moving governance from pre-reasoning constraints toward post-proposal authority/evidence review improves delivery efficiency without reducing correctness.

Do not tune the method to force a successful result. Record failures as first-class evidence.
